Pritisni Očitaj.

Nova DHCP rezervacija

ZTE povezuje MAC uređaja s njegovom stalnom IP adresom. Dodavanje ne mijenja raspon DHCP-a ni gateway.

Provjeri da IP nije već dodijeljen nekom drugom uređaju. Promjene rezervacije mogu zahtijevati obnovu DHCP leasea na klijentu. Brisanje rezervacija u tablici također zahtijeva potvrdu.

RESOLVERS

DNS

Trenutačni DNS parametri ZTE-a te granica između WAN DNS-a i DNS-a koji DHCP oglašava klijentima.

Prijavljene vrijednosti

WAN DNS — postavke

Ovo je WAN DNS routera, ne DNS koji DHCP mora oglasiti klijentima. API ROUTER_DNS_SETTING dokumentiran je na MF297D-srodnim firmwareima, ali nije potvrđen na A1 B08.

DHCP DNS (Option 6) — cilj AdGuard Home

Cilj: ZTE DHCP ostaje uključen i dijeli DNS adresu Beelinka. Ovo nije isto što i WAN DNS. API podrška na A1 B08 još nije potvrđena.

Pokreni provjeru API-ja.

Ne postavljaj javni sekundarni DNS uz AdGuard jer bi klijenti mogli zaobići filtriranje. Prije bilo kakve promjene provjeriti DHCP Option 6 na testnom klijentu.

Port forwarding / firewall pravila

B08 zasad ne vraća inventar pravila niti njihov API format. Za njih nema generičke write naredbe: pogrešan port-forward mogao bi izložiti HAOS internetu. Čim utvrdimo izvorni B08 format, može se dodati editor s inventurom i rollbackom.

Dodatni podaci

Kontrolirani restart routera

Pokreće ZTE Goform REBOOT_DEVICE. Bez tvorničkog reseta i promjene konfiguracije. Kratko prekida internet i Wi-Fi cijele kuće.

Write režim i sigurnost

Tipka Uključi write mode u zaglavlju otključava pripremu promjena i eksperimentalne B08 naredbe. Tipka Isključi write mode blokira nove promjene i poništava sve pripremljene radnje. Sam klik ne kontaktira router. Odabir vrijedi za sve otvorene Manager prozore do restarta App-a; nakon restarta ponovno vrijede HAOS postavke write_enabled i allow_experimental_writes. b08_write_verified ostaje false dok nije potvrđen stvarni uspješan write/readback na A1 B08. Samo otključavanje nije potvrda kompatibilnosti. Za radnje koje prekidaju mrežu uključi i allow_disruptive_changes. Za restart dodatno allow_system_reboot. Ako Wi-Fi mijenjaš, utvrdi wifi_password_format (plain/base64).

DHCP OFF radi tek nakon instaliranog i provjerenog drugog DHCP servera. Pripremi fizički povratak postavki preko ZTE-a prije tog zahvata.
